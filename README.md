# 日本の社会保障

日本の社会保障給付費（年金・医療・介護・福祉等）の推移と、少子高齢化が国の財政に与える影響を解説するWebサイトです。
社会保障給付費・高齢化率のグラフは、ページ表示時にe-Stat（政府統計の総合窓口）APIから最新の公表値を自動取得する
「動的な静的サイト」（サーバー・DB不要、ブラウザから直接APIを呼び出す構成）になっています。

## 見る

依存パッケージ・ビルド不要の静的HTMLです。`index.html` をブラウザで開くか、任意の静的ホスティング（GitHub Pagesなど）にそのまま配置してください。

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 構成

- `index.html` — ページ本体・コンテンツ
- `assets/style.css` — スタイル（ライト/ダークモード対応）
- `assets/data.js` — 静的フォールバックデータ（ライブ取得に失敗した場合に使用。出典は本文末尾「データソース」を参照）
- `assets/estat-config.js` — e-Stat APIのアプリケーションID（appId）設定
- `assets/estat-client.js` — e-Stat API 3.0の汎用クライアント（JSON, CORS対応でブラウザから直接fetch）
- `assets/live-data.js` — e-Stat APIから最新値を取得し、チャート用データに整形。失敗時は`data.js`にフォールバック
- `assets/charts.js` — 依存ライブラリなしのSVGチャート描画・ホバー表示・表切替
- `assets/disqus.js` — 掲示板（Disqus）埋め込み。利用するには `DISQUS_SHORTNAME` の設定が必要

## 動的データについて

- **社会保障給付費の推移・内訳**：e-Stat統計表ID `0004050708`（社会保障費用統計、厚生労働省・IPSS）から取得
- **高齢化率の推移（直近分）**：e-Stat統計表ID `0003448226`（人口推計、総務省統計局）から取得
- **一般会計歳出の内訳**：財務省の予算資料に基づく手動更新（e-Statの「統計」ではなく予算書ベースの数値のため）

いずれもページを開くたびにブラウザから直接e-Stat APIを呼び出します。取得に失敗した場合（通信エラー・API障害・
appId未設定など）は自動的に `assets/data.js` の保存済み数値にフォールバックし、表示が壊れないようにしています。
どちらのデータで表示しているかは、各グラフ横のバッジと画面上部のステータス表示で確認できます。

### appIdについて

`assets/estat-config.js` の `ESTAT_APP_ID` はブラウザから直接呼び出すため、公開ページのソースに露出します。
e-Stat APIのappIdはもともとクライアントサイド利用を想定した設計で秘匿情報ではありませんが、
不正利用等で利用制限がかかった場合は https://www.e-stat.go.jp/mypage/ で再発行し、この値を差し替えてください。

## データについて

社会保障給付費・高齢化率は最新の公表値（本稿執筆時点で2024年度・2024年）、国の一般会計予算（社会保障関係費）は
令和8年度（2026年度）当初予算を基準としています。「社会保障給付費」（保険料・公费を合算した給付総額）と
「社会保障関係費」（国の一般会計における公费負担分のみ）は集計範囲が異なるため、正確な数値・定義は各出典の一次資料をご確認ください。
