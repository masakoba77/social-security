# 社会保障77

日本の社会保障費と国の予算の関係を動的に可視化するサイト

## 概要

本サイトは、日本の社会保障給付費と国の一般会計における位置づけを、最新の統計データを用いて可視化します。

**主な特徴:**
- 社会保障給付費の推移を動的に表示
- 給付費の内訳（年金・医療・介護・福祉等）
- 国の予算に占める割合
- 高齢化率の推移と関連性

## データソース

- **e-Stat** - 政府統計の総合窓口
- **厚生労働省** - 社会保障給付費統計
- **総務省統計局** - 人口推計
- **財務省** - 日本の財政関係資料

## 技術スタック

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript
- **データ可視化**: SVG（ライブラリなし）
- **キャッシング**: LocalStorage
- **API連携**: e-Stat API（予定）

## 使用方法

1. `index.html` をブラウザで開く
2. ページが自動的にデータを読み込み、グラフとテーブルを表示
3. データはブラウザのLocalStorageにキャッシュされ、24時間有効

## 機能

### グラフ表示
- **折れ線グラフ**: 社会保障給付費の推移、高齢化率の推移
- **棒グラフ**: 給付費の内訳、国の予算における位置づけ

### テーブル表示
- 各グラフに対応したデータテーブル
- 年度別、区分別の詳細データ

### レスポンシブデザイン
- モバイル、タブレット、デスクトップに対応
- ダークモード対応
